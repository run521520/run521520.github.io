MYSQL

安装就不用讲了，就讲一些指令和有关的知识

首先要理解数据这个概念，什么是数据，你可以将数据理解为一个最小的存储单位，什么都可以用数据来表示，

就像在计算机中常说最小的单位是字节，所有的数据都是用字节来存储的一样，你也可以这样子理解。

既然数据是最小的单位，那其它的呢？

数据 —–>>> 表 —–>>> 数据库

就是这三个，就是这三个存储了我们看到的信息繁琐的世界，数据就是存储信息的单位，但是这个单位需要放到一个箱子里面来保存它，这个箱子就是表，同理的表也需要一个更大的箱子来保存它，就是数据库了，你可能会疑惑什么的，为什么不将信息存储到一个很大很大的盒子里面，想一下图书馆就可以理解了：一个单独的图书馆需要有一个名字，这个图书馆就是数据库，图书馆里分了很多的藏书区域，这些区域就是表，这些区域会存储拥有同样相关信息的书籍，这些拥有相关信息的书籍就是数据了，你进入到图书馆里面去看书，想看相关的书籍，就是相关的区域，目标很明确的。

但是你想一下，一个图书馆里没有任何的知识区域的区分，你要看某一相关的书籍怎么办，只能一个一个的寻找了费时费力，在计算机中也是同样的，浪费的时间会影响用户的体验等，这就会导致其它的负面影响。

理解它们之间的关系后就是指令了，首先MYSQL在安装的时候是没有可视化操作界面的，但是有一个操作窗口，找到你安装的目录，一样是这样子的**C:\Program Files\MySQL\MySQL Server 8.0\bin** 默认是C盘下的**Program Files** 文件不是 Program Data这里面的是存储MYSQL数据的，在该目录下找到mysql.exe不要直接点击，因为会出现一瞬先的退出操作，需要打开命令窗口，在这里面进行打开

输入**mysql.exe -u root -p** 然后确定就是输入密码了，输入正确就进入黑窗口了，进行操作了

解释一下输入 mysql.exe 点击确定是不行的，需要同时输入用户的身份 -u 就是用户的意思后面跟着 root 就是用户了这里**-u和root**

是可以挨着的，也可以空一格，看自己吧，后面有了用户就需要密码了**-p就是password**的意思你可以将密码写在后面，但是会显示出来，所有你可以按确定，密码可以在下一行写

看一下这两个操作，还有就是第一种这个在**-p**和后面的密码之间不要有空格，不然会报错

指令

在MYSQL中常用结构化查询语言，包含DDL、DML、DQL、DCL。

  • DDL：数据定义语言，主要进行定义或改变表的结构、数据类型、表之间的连接等操作，常见的关键字有**create ， drop , alter**
  • DML：数据操作语言，主要对数据进行增加删除修改等操作，常用的关键字有**insert , update , delete**
  • DQL：数据查询语言，查询操作，常用关键字**select , from , where**
  • DCL：数据控制语言，主要用来设置或更改用户权限，常用的关键字有**grant , revoke**

约束

在这里的约束，意思是为了更好的管理数据，将数据更好，更方便的存储到表里保证数据的完整性、一致性和准确性

实体完整性：主键（primary key）、唯一（unique）→ 保证行数据唯一

域完整性：外键（foreign key）、默认（default）、非空（not null）→ 保证列数据合法

  1. 主键约束：唯一标识表中的每一行数据，且值非空 + 唯一(不重复)

  2. 唯一约束：保证字段的值唯一（可以有多个唯一约束），但允许有一个 NULL 值

  3. 外键约束：建立两个表之间的关联，保证「子表」的数据必须在「父表」中存在（维护数据关联性）

    往 order_info 插入 user_id=999（但 user 表中没有 999 这个用户），会报错。

  4. 默认约束：插入数据时，如果没有给该字段赋值，自动填充默认值。

  5. 非空约束：强制字段的值不能为 NULL（必须填值）

    主键：唯一 + 非空，表的「唯一标识」，一个表仅 1 个；

    唯一：仅保证值唯一，允许一个 NULL，可多个；

    外键：关联两张表，保证子表数据在父表中存在；

    默认：未赋值时自动填默认值（如性别默认男）；

    非空：字段必须填值，不能为 NULL（如用户名必填）。

逻辑运算符

  • not表示非
  • and表示与，两个条件都为真时才返回1。
  • or表示或者，只要其中任意一个为真就返回1。
  • 优先级： not and or

比较运算符

  • != ：不等于
  • IS NULL : 是否为空
  • IS NOT NULL : 是否不为空
  • IN : 判断一个值在这个列表里
  • NOT IN :判断一个值不在这个列表里

三个表达式：

- 表名后：字段判断  
- `select`后：目标表达式
- `where`后：条件表达式

增删改数据

添加数据

insert [into] 表名 (字段1，字段2，字段3) values (值1，值2，值3)

  • 如果插入所有字段，可以不用指明字段，但一定按照字段顺序填入值
  • 若插入部分字段，字段和值要对应，可以不按照表中字段顺序
  • 自动增长列可以不用指定值，0或用null代替；
  • 有默认值约束的列不指定值时将使用默认值；

这种是一次插入一行数据，下面的是多行

insert into 表名 (字段1，字段2，字段3) values (值1，值2，值3)， (值1，值2，值3)

修改数据

update 表名 set 字段1=值1，字段2=值2 where 条件

  1. 修改表中的全部数据
  2. 根据条件修改表中的数据

删除数据

delete from 表名 where 条件

  1. 删除StudentInfo表中所有的记录
  2. 根据条件删除表中的数据
