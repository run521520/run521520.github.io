这里看一下 RegisterNatives 函数的用法，才能更明白
RegisterNatives 的第三个参数是数组，第四个参数 3 表示有 3 个 结构体。每个结构体占用 3 个指针（在 32 位 so 里是 3 个 4 字节，共 12 字节）。

什么意思？解释一下RegisterNatives(env,class,arrs[],num)

  • env JNI 环境指针,提供所有 JNI 函数调用
  • class 要注册 native 方法的 Java 类
  • arrs[] 方法映射数组
  • num 数组长度
