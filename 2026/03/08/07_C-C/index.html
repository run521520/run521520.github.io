LoadLibraryA

LoadLibrary 函数是 Windows API 中用于加载 DLL（动态链接库）或可执行模块到调用进程的地址空间的函数。这个函数不仅可以加载指定的模块，还可能导致其他模块的加载。如果需要更多的加载选项，可以使用 LoadLibraryEx 函数。

参数 lpLibFileName 是要加载模块的名称，可以是 DLL 文件或 EXE 文件。如果提供的是完整路径，函数只会在该路径下搜索模块。如果提供的是相对路径或仅模块名称，函数会使用标准搜索策略来查找模块。如果函数无法找到模块，它将失败。在指定路径时，应使用反斜杠（\），而不是正斜杠（/）。

返回值：

如果函数调用成功，它会返回模块的句柄。如果调用失败，返回值为 NULL。为了获取更多的错误信息，可以调用 GetLastError 函数。

注意：

  • 使用 LoadLibrary 时，如果指定的模块是 DLL 并且尚未加载到调用进程中，系统会调用 DLL 的 DllMain 函数。如果 DllMain 返回 TRUE，LoadLibrary 将返回模块的句柄；如果返回 FALSE，系统会卸载 DLL，并且 LoadLibrary 返回 NULL。
  • 模块句柄不是全局的或可继承的。一个进程调用 LoadLibrary 不会产生另一个进程可以使用的句柄。另一个进程必须自己调用 LoadLibrary才能使用模块。
  • 如果 lpFileName 不包含路径，并且有多个具有相同基本名称和扩展名的已加载模块，函数将返回首先加载的模块的句柄。
  • 如果在 lpFileName参数中未指定文件扩展名，则会附加默认库扩展名 .dll。但是，文件名称字符串可以包含尾随点字符（.），以指示模块名称没有扩展名。

GetProcAddress

*GetProcAddress函数是Windows API中的一个函数，它用于从指定的动态链接库（DLL）中检索导出函数或变量的地址。这个函数非常重要，因为它允许程序在运行时动态地链接到DLL中的函数，这就是所谓的运行时动态链接。

其中，hModule是包含函数或变量的DLL模块的句柄，可以通过LoadLibrary、LoadLibraryEx、LoadPackagedLibrary或GetModuleHandle函数获得。lpProcName是函数或变量的名称，或者是函数的序号值。如果这个参数是一个序号值，它必须在一个字的底字节，高字节必须为0。

在这个示例中，我们首先使用LoadLibrary函数加载了名为”MyDll.dll”的DLL文件，然后使用GetProcAddress获取”MyFunctionName”函数的地址，并将其转换为适当的函数指针类型。如果函数地址成功获取，我们就调用这个函数。最后，使用FreeLibrary函数卸载DLL。
