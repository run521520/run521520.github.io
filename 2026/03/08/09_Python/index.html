Python

数据类型

有整数（int），浮点数（float），布尔值（bool），空值（None），字符串型（Str），这些是简单的，剩下的还有；

在Python中布尔值是大写的（True，False），其中True也可代表1，False也可代表0

可以看到布尔类型本质还是整形，在进行运算的时候可以当成整形在运算

数据类型知道了，那就用变量来存储数据，变量就是容器，简单的存储数据变量名 = 变量的值

Python是动态类型语言，就是在程序运行时才进行检查，所以变量的类型在程序运行中是可以改变的，但是常见的就是一个变量对应一个数据类型

变量名的定义要求：只能包含字母，数字，下划线，不能以数字开头，区分大小写

  • 见名知意
  • 多个部分以_连接（蛇形命名法）
  • 英文字母全小写

可以通过Python内置的**type(data)**来查看数据类型

也可以通过另一个内置函数**isinstance(data,type)**来检查是否为指定的类型，返回值为bool

字符串

定义

Python中的字符串有三种定义的方式：

  • 双引号
  • 单引号
  • 三引号（多行字符串）

可以发现三引号是可以换行的，但是双引号，单引号不可以

转义符：\

常见的有：

  • \' :'
  • \" :"
  • \n :换行符
  • \t :制表符，一个tab键缩进

所以在字符串中有时要存储:It’s a good boy等带有',"可以使用转义符来表示

另一种方法就是双引号和单引号的混用的区别，在单引号的str中里面有双引号，这个双引号就是按照双引号来存储，同理在双引号的str中里面的单引号也是按照单引号来存储

拼接

这里我们可以使用**str(data)**来将int类型转换为str类型

这种写法用+和str来写一些简单的语句是可以的，但是在一些复杂语句中就显得麻烦和臃肿了

内置函数

  • find() 在字符串中查找子串第一次出现的位置，没找到为-1
  • count() 统计子串在字符串上出现的次数
  • upper() 将字符串中的小写字母转换为大写字母
  • lower() 将字符串中的大写字母转换为小写字母
  • split() 将字符串按指定的分割符割成列表
  • strip() 去除字符串两端的空白字符，或指定字符
  • replace() 将字符串中指定的字串替换成新的字符
  • startswith() 检查字符串是否以指定字串开头，返回布尔值
  • endswith() 检查字符串是否以指定字串结尾，返回布尔值

列表(list)

用来存储多个数据元素的集合

和其它语言的数组形式有点像，但又是不同的，首先这个列表的定义是lists = [data1 , data2 , data3 ,.... datan]但是里面的元素是可以为不同类型的。

其次就是访问元素的方式，可以是正向访问的0~n也可以逆向访问-(n+1)~-1

且列表的获取和修改和数组一样，但是这个又可以删除操作del来操作

切片

用来操作列表，提取列表相关的元素，该操作的结果可以叫做子列表

另外的一点就是当步长为-1表示从后往前且步长为1，这就意味着可以通过切片来实现列表反转

内置函数

  • append(data) 在列表的末尾插入元素
  • insert(index,data) 在指定索引之前，插入该元素
  • remove(data)移除列表第一个配置的元素
  • pop() 删除列表中指定索引的元素，没有索引默认删除最后一个，且会返回该删除的元素
  • sort() 排序，这个是升序排序
  • reverse() 反转列表元素

在做一个python编译封装的exe题时，正常的ida是没办法反编译的
所以我们需要几个工具来帮助我们完成反编译

pyinstxtractor.py 脚本

将要反编译的exe放到同目录，打开终端输入 python pyinstxtractor.py xx.exe // xx.exe 是你要编译的程序名字，然后会生成一个以_extracted后缀结尾的文件夹，打开之后
找到”目标文件名.pyc”的文件（往往与struct.pyc一并出现，都有用）

进行完上述操作之后，可能会遇到文件头结构需要补充修改的情况，就是讲xx.pyc和struct.pyc两个pyc文件放入010查看xx.pyc的文件头是否与struct.pyc相同，不同的话要把后者的内容补充上去（目前做题还没遇到过这样的情况）再进行下一步操作。

uncompyle6 反编译pyc文件（当用python版本超过3.12后便没用了）

在命令行中输入 uncompyle6 xxx.pyc > xxx.py 前面的是要反编译的文件，后面的是生成的文件

pycdc 程序（支持3.12以上的版本）
找到pycdc的文件中的build后复制
pycdc.exe pycdas.exe 程序到 xx.pyc同一目录
打开终端 输入 ./pycdc xx.pyc 然后便反编译成功了

函数：
在Python中，定义一个函数要使用def语句，依次写出函数名、括号、括号中的参数和冒号:，然后，在缩进块中编写函数体，函数的返回值用return语句返回。如果没有return语句，函数执行完毕后也会返回结果，只是结果为None。return None可以简写为return。

返回多个值：在其他语言中，一般只能返回一个值或者一个数组、对象，在Python中，可以通过tulp变通的返回多个值。

Python的函数定义非常简单，但灵活度却非常大。除了正常定义的必选参数外，还可以使用默认参数、可变参数和关键字参数，使得函数定义出来的接口，不但能处理复杂的参数，还可以简化调用者的代码。

这里介绍以下 z3 用来解线性方程组
例如： a13+a22 = num1;
a24+a3 = num2;
a35+a1*7 = num3;
这种，当未知数多的时候便不是，在短时间内解出的了

from z3 import *

v1,v2,v3 = Ints(‘v1,v2,v3’) #带不带逗号都行，也可以用空格
当是数组的时候就是 X = [Int(f'x{i}') for i in range(25)]
s = Solver()

s.add(a13+a22 == num1)
s.add(a24+a3 == num2)
s.add(a35+a1*7 == num3)

if s.check() == sat:
m = s.model()
for var in [v1,v2,v3]:
print(f”{var} = {m[var]}”)
#这里m[var]是一个z3的变量，不可以直接运算，如果要是它在后面加上as_long()，就会变成python类型
#v1 = m[v1].as_long()
else:
print(“无解”)
